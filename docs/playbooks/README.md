# Role playbooks

Focused workflows for common contributor roles, where each playbook lists prerequisites, a gate checklist, and troubleshooting paths; begin with the [contributor playbook](../contributor-playbook.md) for shared setup and local CI before opening a role-specific track.

| Playbook | Role |
|----------|------|
| [formalizer.md](formalizer.md) | Add or extend Lean formalizations and link to claims |
| [reviewer.md](reviewer.md) | Review pull requests and artifact impact |
| [domain-expander.md](domain-expander.md) | Admit the first paper in a new domain |
| [release-manager.md](release-manager.md) | Cut a tagged release with signed artifacts |

Proof-carrying science releases are documented in [pcs/README.md](../pcs/README.md).
